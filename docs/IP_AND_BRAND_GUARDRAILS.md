# IP and Brand Guardrails

Hellbindah is an ode to 1990s Windows sci-fi flight shooters. It must not ship as a clone or unauthorized remake.

## Do not use without written rights clearance

- Original game titles or confusingly similar commercial branding.
- Original executable, data files, models, textures, sprites, UI art, logos, fonts, music, sound effects, voice lines, or mission text.
- Original character names, faction names, dialogue, plot text, level names, or distinctive proprietary terminology.
- Ripped screenshots or derived assets.

## Allowed homage patterns

- Fast arcade 6DOF flight.
- Retro-futurist chunky sci-fi art direction.
- Surface-base, tunnel, reactor, switch, cache, and extraction mission structures.
- Original weapons that preserve broad gameplay roles without copying names or assets.
- Original ship-computer callouts and mission story.

## Review checklist

Every content PR must answer:

- Is every asset original, properly licensed, or clearly placeholder?
- Could a player mistake this for an official Microsoft/Terminal Reality product?
- Are any original names, text, sounds, or models copied?
- Are all third-party asset licences recorded?

If uncertain, block the PR and create a research/legal task.
